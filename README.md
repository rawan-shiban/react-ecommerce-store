# 🛒 React E-commerce Store

> ⚠️ **Work in Progress** — This is my learning project,
> currently being rebuilt from a tutorial with plans to
> expand into a full-featured e-commerce app.

##  Project Goal

My goal is to build a **complete e-commerce store** from scratch,
going beyond the tutorial by adding:
- User authentication
- Real checkout flow
- Order history
- Admin dashboard
- Arabic translation (RTL)

##  Current Status: v0.1 (Learning Phase)

This version includes:
-  Home page with categories
-  Product details page
-  Shopping cart (in progress)
-  Favorites page
-  Search functionality
-  Category pages

##  Tech Stack

| Technology | Purpose |
|------------|---------|
| React | UI library |
| React Router | Routing |
| Framer Motion | Animations |
| Context API | Cart state |
| React Icons | Icons |
| React Hot Toast | Notifications |
| DummyJSON | Fake API |
| Vite | Build tool |
